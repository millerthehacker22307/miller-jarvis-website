Built like a big assistant, in miniature

The same architecture the large AI assistants use — a reasoning brain, permanent memory, a scheduler and tools — packaged to run on a normal student laptop.

🧠

Reasoning Brain

A local open model (Qwen 3.5, 4B) served by Ollama, prompted to think step by step before answering — so maths, logic and planning come out structured, not guessed.

💾

Permanent Memory

Tell it a date, a plan or a preference once — it is saved on disk and brought into every future conversation. Close it, restart the laptop, it still remembers.

⏰

Task Scheduler

One-time reminders, daily routines, and agent tasks that fire on time in the background — even while you are busy studying.

🤖

Agent Tasks

Not just reminders — schedule real work: "tomorrow 7 AM, prepare 10 revision points." Jarvis does the work at that time and saves the result for you.

🛠️

Real Tools

A safe calculator, a notebook, a web page reader, the clock and system info — the assistant acts, not just chats.

🔒

Fully Private

Model, memory and results all live in one folder on your machine. Works offline. Delete one file and its memory is wiped — you are in control.

Commands that always work

Core commands are handled in code, not by the model — they never fail.

/remember <fact>Save a fact forever
/factsShow everything it remembers
/schedule 2026-10-22 07:00 <task>One-time reminder
/agent 2026-10-22 07:00 <task>Jarvis does the work at that time
/daily 07:00 <task>Daily reminder
/tasksList pending tasks
/done <id> · /forget <id>Complete a task · delete a fact

Honest limits

A 4B local model is not a frontier cloud model. It is genuinely strong at routine reasoning, summaries, planning, memory and scheduling — and weaker at very hard problems. On CPU it answers at a modest speed, which is perfectly fine for background scheduled work. For the heaviest work, pair it with a full cloud assistant; for everyday work, Jarvis is free forever.
